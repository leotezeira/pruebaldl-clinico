# Manual: llevar el LDL a la estética del Audiómetro Clínico Pro

Objetivo: que `ldl.html` se vea y se sienta como parte de la misma app (mismo lenguaje visual, misma navegación, mismos componentes), sin romper la lógica que ya funciona.

---

## 0. Diagnóstico: qué difiere hoy

| Aspecto | Audiómetro (referencia) | LDL actual | Acción |
|---|---|---|---|
| Estructura | `index.html` + `css/` + `js/` modulares | Todo en un solo `ldl.html` | Separar en archivos |
| Navegación | Barra inferior fija con 5 pestañas e íconos SVG | Secciones que se ocultan con `go()`, sin barra | Agregar `.nav` inferior |
| Encabezado | `.header` (sub en mayúsculas + h1 + divider degradé) | `<h1>` simple con emoji | Usar `.header` |
| Botones | Fondo blanco, **borde y texto de color**, sube 2px al hover | Rellenos de color sólido | Usar `.btn .btn-*` |
| Íconos | Sprite SVG inline (`<use href="#i-...">`) | Emojis (🔊 ⚙️ 📊) | Reemplazar por sprite |
| Tema | Claro, "health-tech" | Claro + modo oscuro automático | Dejar solo claro (consistencia) |
| Colores de oído | **OD = azul `#2563eb` ○ · OI = teal `#14b8a6` ×** | Derecho = **rojo**, Izquierdo = azul | Unificar con `COLOR_OD/OI` |
| Tarjetas | `.card` con título uppercase azul de 12px | Bordes laterales de colores por sección | Usar `.card` + `.card-title` |
| Gráficos | `.audiogram-wrap` con título y leyenda | `<div class="card">` con SVG | Usar `.audiogram-wrap` |

> Regla de oro: **no inventes estilos nuevos si ya existe una clase en `styles.css`**. El LDL debe cargar el mismo `styles.css` y solo sumar un `ldl.css` pequeño para lo específico.

## 1. Estructura de archivos recomendada

Dentro de `public/` (para que el deploy de GitHub Pages y el service worker lo tomen):

```
public/
├── index.html            ← Audiómetro (ya existe)
├── ldl.html              ← NUEVO shell del LDL (HTML limpio)
├── css/
│   ├── styles.css        ← compartido, NO duplicar
│   └── ldl.css           ← solo lo específico del LDL
└── js/
    ├── constants.js      ← compartido (COLOR_OD, COLOR_OI, etc.)
    ├── ldl/
    │   ├── ldl-state.js      (conds, res, L, START, STEP, cal…)
    │   ├── ldl-audio.js      (tone(), NB(), init())
    │   ├── ldl-calibration.js(RET, buildCal, calc, offK)
    │   ├── ldl-charts.js     (grid, chart, bars, evo, cmp)
    │   ├── ldl-storage.js    (loadH, saveS, delS, backup/restore, csv)
    │   ├── ldl-ui.js         (go, show, render, hist)
    │   └── ldl-app.js        (wiring de eventos)
```

Pasos:
1. Mové `ldl.html` a `public/ldl.html`.
2. Sacá el `<style>` y el `<script>` inline. El CSS que quede específico va a `ldl.css`; el JS se parte en los módulos de arriba **sin cambiar la lógica** (solo cortar y pegar funciones).
3. Agregá `ldl.html`, `css/ldl.css` y `js/ldl/*.js` a `CORE_ASSETS` en `sw.js` y subí `CACHE_VERSION` a `"v3"`.
4. Agregá un acceso cruzado entre ambas apps (ver sección 9).

> Importante: usá una clave de storage distinta (`ldl_hist_v1`, `ldl_cal` ya lo son). No la mezcles con `audiometro_historial`.

## 2. Design tokens (copiar tal cual desde `styles.css`)

El LDL **no redefine** variables: hereda `:root` de `styles.css`. Solo agregá en `ldl.css` los tokens propios:

```css
/* ldl.css */
:root {
  --range-color: #7c3aed;   /* rango dinámico */
  --ldl-color:   #f59e0b;   /* marcador LDL (reutiliza --warning) */
  --ldl-normal:  #10b981;   /* zona LDL normal ≥ 90 dB HL (reutiliza --success) */
}
```

Paleta que ya existe y debés usar:

| Token | Valor | Uso en LDL |
|---|---|---|
| `--primary` | `#2563eb` | títulos de tarjeta, estado activo, OD |
| `--secondary` | `#14b8a6` | OI |
| `--success` | `#10b981` | "Iniciar", "Correcta", LDL normal |
| `--danger` | `#ef4444` | "Es molesto", borrar |
| `--warning` | `#f59e0b` | LDL medido, avisos |
| `--bg / --surface / --border` | `#f8fafc / #fff / #e2e8f0` | fondo, tarjetas, bordes |
| `--text-primary/secondary/muted` | `#0f172a / #334155 / #64748b` | jerarquía de texto |

Tipografía: la misma pila del `body` (system-ui). Tamaños: título de tarjeta 12px uppercase `letter-spacing:2px`; `h1` 26px; valores grandes 36px (`.db-display`).

Todos los SVG deben vivir dentro de:

```html
<div class="audiogram-wrap">
  <div class="audiogram-title"><svg class="icon"><use href="#i-audiogram"></use></svg> Oído derecho</div>

    <span style="color:var(--ldl-color)">■ LDL</span>
```

Reglas para `ldl-charts.js`:

1. **Colores por oído**: OD = `#2563eb` con símbolo ○; OI = `#14b8a6` con símbolo ×. En el código del LDL cambiá:
   ```js
   const COL = ["var(--rd)", "var(--ac)"];   // ❌ hoy
   const COL = [COLOR_OD, COLOR_OI];          // ✅ (de constants.js)
   ```
   Y en `chart()`: el oído derecho dibuja círculo azul, el izquierdo "×" teal (hoy usa rojo/azul).
2. **Grilla**: líneas `rgba(15,23,42,0.12)`, 0.5px (1px en múltiplos de 20); etiquetas `rgba(15,23,42,0.55)`, tamaño 8–10.
3. **Eje Y**: mismo rango y orientación que el audiograma (0 arriba, 120 abajo, "dB HL").
4. **Zona normal**: reemplazá la franja verde actual por la misma convención que el audiómetro (fondo `rgba(124,163,200,0.05)`) y dejá una línea punteada `--ldl-normal` en 90 dB HL con la etiqueta "LDL normal ≥ 90".
5. **Variables CSS dentro del SVG**: al usar SVG inline (no `<img>`) las `var(--x)` funcionan; mantenelo así.
6. Quitá cualquier `var(--card)` que haya quedado de la versión oscura: usá `#fff`.

## 8. Navegación y lógica: cómo reemplazar `go()` sin romper nada

Mantené los ids de todos los elementos (`pn`, `pa`, `stim`, `who`, `mode`, `mx`, `stp`, `st0`, `off`, `start`, `play`, `up`, `dn`, `mol`, `nomol`, `hp`, `hl`, `tb`, `charts`…). Solo cambiá el router:

```js
// ldl-ui.js
const PAGES = ["pg-paciente", "pg-config", "pg-prueba", "pg-resultado", "pg-historial", "pg-calibracion"];

// Mapa del código viejo → páginas nuevas (así no tocás el resto)
const LEGACY = { s0: "pg-config", s1: "pg-prueba", s2: "pg-resultado", s3: "pg-historial", s4: "pg-calibracion" };

function go(id) {
  const pageId = LEGACY[id] || id;
  PAGES.forEach(p => document.getElementById(p).classList.toggle("active", p === pageId));
  document.querySelectorAll(".nav-btn").forEach(b =>
    b.classList.toggle("active", b.dataset.page === pageId ||
      (pageId === "pg-calibracion" && b.dataset.page === "pg-config")));
  window.scrollTo(0, 0);
  if (pageId === "pg-historial") hist();
}

document.querySelectorAll("[data-page]").forEach(el =>
```
